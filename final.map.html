@construct-space/sdk — Surface Map v0.11.x (working toward v1.0)

TypeScript types + reactive composables + Zod schemas for building external Construct Spaces. Pure declarations — the host injects runtimes via window.__CONSTRUCT__['@construct-space/sdk']. UI primitives live in @construct-space/ui; this package does not re-declare them.

Surface boundary. External Spaces consume this SDK only. Internal built-in Spaces (frontend/spaces/*) reach into host private APIs directly. Agent RPC, model selection, assistant chat, host chrome (toasts, panels, OS/runtime info, i18n, theme), and design-canvas surfaces are deliberately not here — Spaces declare actions in actions.ts and the agent calls them. One-way.

Vue composables exposed by the host runtime. All declared as declare function — types only; bodies come from window.__CONSTRUCT__. Grouped by domain; rough order of how often a Space needs each.

Who's signed in, what they're allowed to do, and per-resource sharing.

useAuth()Auth store proxy (user, token)

Toolbar & Breadcrumb 2

Host-toolbar contributions only. Panels, splitters, popovers, dropdowns — all UI composition; use @construct-space/ui components (<SplitPane>, <DashboardPanel>, <Dropdown>, <Popover>). Theme is plain CSS variables — no composable.

useToolbar()Toolbar action items + search
useBreadcrumb()Declare the trail; host renders it in the toolbar slot

Routing & Shortcuts 2

In-Space router (thin shell over vue-router) + per-Space keybinds.

Networking & Data 3

HTTP client, file storage, per-space KV. For typed models use @construct-space/graph. Do not bring axios/ky/dio — useHttp is the client.

useHttp()Full HTTP client (get/post/put/patch/delete, JSON, retry, interceptors, .create() scoped)
useStorage()File storage — root is {space_id}/<path>
useLocalStorage()Per-space KV (IndexedDB, persistent)

Messaging 2

Spaces fire notifications + send email. Host owns the bell, inbox, push enrollment, mark-read, prefs. <Toast> + useToast() live in @construct-space/ui for "file saved" style transients.

useNotification()send(input) — fire one notification. Host owns bell/inbox/push.
useDelivery()Outbound email (Construct-branded; layout fixed)
